# Parity with Slidev

What slide.ng has of Slidev's features, row by row. Sources read: `docs/guide`, `docs/features`, `docs/builtin`, `docs/custom`, `docs/resources`,
`packages/types/src/frontmatter.ts`, `packages/parser/src/config.ts`, `packages/slidev/node/cli.ts`, `packages/client/setup/shortcuts.ts` and `logic/shortcuts.ts`.

**Status words.** `done`: works and a test for it was found (the "test:" note names the check; every one of them was run in the last
full test run, see STATUS.md). `partial`: some of it works, the note says what is missing. `not done`: not there. `different by design`: the same job
done another way. `not done (skipped on purpose)`: left out by the project's own decision. A row with no test says `not verified`.

How "test:" was chosen: this file was produced from a table in which every `done` row lists the names of checks. A script searched the
browser tests (`tests/e2e`, `tests/export`) and the unit specs for each name; a name that is not found turns the row into
`not verified`. Finding a name proves the check exists; the suites were run to prove that it passes.

Names: where Slidev writes `v-click`, `<v-clicks>`, `<Toc />` or `<youtube>`, slide.ng writes `slide-ng-click`, `<slide-ng-clicks>`, `<slide-ng-toc />` or `<slide-ng-youtube>` (all built-ins have the `slide-ng-` prefix, see RENAMES.md). Rows below use the new names, and Slidev's component name where the row is about Slidev's feature.

Slidev is Vue and Vite; slide.ng is Angular. Anything that is about Vue, Vite plugins or Slidev's own theme packages is "different by design" or "not done".

## The biggest gaps, ranked

1. **Community Slidev themes and addons cannot be used.** They are Vue packages. slide.ng has its own contract (docs/THEMES.md), the four official themes rebuilt on it (separate slide-ng/themes repository) and one example theme; there is no ecosystem.
2. **Setup hooks are there (docs/SETUP.md)**, with these gaps: Monaco type loading (`monacoTypes*`, so Monaco does not know package types), markdown-it plugins in transformers, and a run context for code runners.
3. **`fonts`** is read (names, local, weights, italic, fallbacks, provider) and loaded from the provider at run time, as in Slidev; `selfHost` copies them into the build (default for `pwa` and `build --offline`), tested with a fake provider only.
4. **Export**: editable PPTX is not made, `export` takes one entry, PDF/PNG need a local Chromium (`--executable-path` or `CHROME_PATH`).
5. **Animations**: custom transition objects, `preloadImages`, slide `preload` and the slide hooks (`onSlideEnter`, `onSlideLeave`) do not exist; `slide-ng-motion` has no motion presets.
6. **Touch**: swipe navigation works; pinch zoom and touch handling for drawing and `slide-ng-drag` were not tried on a real device.
7. **UI**: `selectable` and `themeConfig` are not there.
8. **Syntax**: MDC/Comark syntax is not parsed. The markdown inside a slide is converted with `marked`, so the markdown-it typographer (smart quotes, `--`, `...`) does not run, and `v-pre` is Angular's `ngNonBindable` (or write `&#123;&#123;` for a literal `{{`). UnoCSS attributify, variant groups and the typography preset (`prose`) are not installed.
9. **CLI**: dev `--base`, `--tunnel`, build `--router-mode`, `--inspect`; the dev server's default port differs (4230).
10. **Recording and PWA**: no separate camera file and no mp4 or mkv; the PWA part is done (its first visit must be online, like Slidev's; `build --offline` is the answer for talks with no network).
11. **Size**: the first load of a deck with Monaco and KaTeX is about 850 kB (budget raised to 1.5 MB warning, 3 MB error).
12. **Unverified ground**: Firefox and Safari, real devices over a LAN, a real screen-share picker, wake lock behaviour and hosts that need hash routing were not tried (STATUS.md, NOT VERIFIED).
